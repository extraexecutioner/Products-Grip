
Front-end слой (Интерфейс)

Vue 3 (Composition API + Vite).
Tailwind CSS

Back-end слой (Распределенная система)

Express: Сервис 1. Берет на себя авторизацию (GitHub OAuth2), сессии и валидацию пользователей. Он же держит Socket.io для моментального стриминга логов исправления прямо на фронтенд во Vue.

NestJS (на движке Fastify): Сервис 2 (Оркестратор). Главный мозг бэкенда. Он принимает очищенные данные от Express, координирует запуск Docker-контейнеров, собирает финальные логи исправлений, упаковывает «чистый» проект в .zip архив и отдает его пользователю.

Python (FastAPI): Сервис 3 (ИИ-Анализатор). Работает с кодом и нейросетями. С помощью локальной LLM находит уязвимости, предлагает патчи для авто-исправления и тестирует код в песочнице.

Инфраструктурный слой (Связующие звенья)

Apache Kafka: Брокер сообщений, через который Express, NestJS и Python мгновенно обмениваются задачами и логами асинхронно.
